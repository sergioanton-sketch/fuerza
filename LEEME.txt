FUERZA 20 – versión actualizada

Contenido:
- Planificación diaria completa para semanas de 3 y 5 días.
- Selección de fecha y cambio manual de sesión para recuperar entrenamientos.
- Cargas programadas de press banca y banca pausada según las 20 semanas.
- Progresión de dominadas según la semana y el turno.
- Para ejercicios auxiliares, propone la última carga registrada y orienta el siguiente incremento si el último registro fue fácil (3+ RIR). En la primera sesión se debe calibrar una carga que permita 2 RIR; no se inventan pesos sin conocer la fuerza individual.
- Registro de peso, series, repeticiones, RIR, sensaciones y observaciones.
- Historial, CSV, copia/restauración JSON, temporizador y fotos locales.

Instalación/publicación:
1. Descomprime el ZIP.
2. En GitHub, abre el repositorio sergioanton-sketch/gimnasio.
3. Add file > Upload files; sube y reemplaza los archivos de esta carpeta en la raíz.
4. Commit changes.
5. En Settings > Pages comprueba Deploy from a branch, main y /(root).
6. Espera a que Actions termine correctamente y abre https://sergioanton-sketch.github.io/gimnasio/

La aplicación no se publica automáticamente desde este ZIP. Requiere subir los archivos a GitHub Pages y disponer de HTTPS.
Los datos se almacenan localmente en el navegador. Exporta copias JSON regularmente.
Suunto no está conectado; la introducción de datos sigue siendo manual.
